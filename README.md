# Nexora Free Lite

Nexora is a polished, responsive multi-page HTML template for IT companies, digital transformation studios, web developers, freelancers, and small agencies.

**Live preview:** https://cholbei.github.io/nexora-free-lite/

**Created by:** [Cholbei](https://cholbei.com/)

## Included pages

- Home and 404
- Web Development, Digital Marketing, SEO, and AEO/GEO
- Domain & Hosting, E-commerce, UI/UX, Graphics, IT Consultancy, and Video Production
- Fictional client showcase

## Quick start

No build step is required. Clone the repository and open `index.html`, or serve the folder with any static web server.

```bash
git clone https://github.com/cholbei/nexora-free-lite.git
cd nexora-free-lite
```

See [DOCUMENTATION.md](DOCUMENTATION.md) before publishing.
